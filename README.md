# 深度学习制作企业产品预测系统 V3.0

这是第三轮的开发样本整理和训练准备项目。已完成样本整理，并完成一次很小范围的模型、预测上下范围和成绩文件连通检查；尚未进行 525 户学习、113 户确定上下范围、142 户开发测试的正式比较，也没有生成新的最终大考企业。

## 资料口径

- `data/samples/`：每个权威来源只保留一套日余额、逐笔流水、备注、实际配置和已绑定图片；来源映射在 `data/manifests/`。
- `data/manifests/`：来源、校验值、家族、使用历史、入组与异常清单。
- `src/`、`tools/`、`configs/`、`assets/`：可复用代码、预算/生成器及必要资源。
- `reports/`：中文阶段报告、总图册和最终交付说明。
- `runs/logs/`：只追加的执行日志。

“余额和收支”资料只含预测日以前的日余额与实际发生收支；“增加收支用途信息”资料在前者基础上，将交易备注按交易编号、金额、方向与日期核对后分类。未知用途保留为未知，未来合同计划或完整未来走势绝不进入资料。

## 当前进度

已完成来源文件迁入、基础账务核对、全量近复制/走势/曲线重复检查、按日期用途资料、98页图册与图页对应记录，以及八种方法乘三种资料的小规模可运行核对。训练安排以 [第三轮训练测试方案书](docs/第三轮训练测试方案书_20260922.md) 和 [第三轮训练测试执行计划](docs/第三轮训练测试执行计划_20260922.md) 为准：下一银行营业日余额、10 日均余额和 30 日均余额是当前三项任务。

小规模核对的事实、文件位置和限制见 [模型适配与上下范围评分小规模核对](reports/模型适配与上下范围评分小规模核对_20260923.md)。它只证明程序能完整读入、预测、确定范围和写出成绩文件，不能作为方法优劣或最终大考结论。
