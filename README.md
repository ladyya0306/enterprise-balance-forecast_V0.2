# 深度学习制作企业产品预测系统 V3.0

这是第三轮的**开发样本整理项目**。本项目仅整理、核验和交付既有样本及其可复用资产；不训练模型、不运行模型考试，也不生成新的企业或正式新大考。

## 资料口径

- `data/samples/`：每个权威来源只保留一套日余额、逐笔流水、备注、实际配置和已绑定图片；来源映射在 `data/manifests/`。
- `data/manifests/`：来源、校验值、家族、使用历史、入组与异常清单。
- `src/`、`tools/`、`configs/`、`assets/`：可复用代码、预算/生成器及必要资源。
- `reports/`：中文阶段报告、总图册和最终交付说明。
- `runs/logs/`：只追加的执行日志。

“余额和收支”资料只含预测日以前的日余额与实际发生收支；“增加收支用途信息”资料在前者基础上，将交易备注按交易编号、金额、方向与日期核对后分类。未知用途保留为未知，未来合同计划或完整未来走势绝不进入资料。
