# SYN-B1新生成器代码边界

本目录是版本4.0“单企业完整现金循环＋融资生命周期”的唯一业务代码根目录。

## 已有代码

- `cash_plan.py`：I1月度现金计划、事件预算和融资前缺口预览；已经验收。

## 后续计划

- `operating_cycle.py`：I1A销售、回款、采购、生产、费用、税费和投资月度计划；
- `statement_rollforward.py`：I1B利润表、资产负债表和现金流量表滚动与勾稽；
- `financing.py`：I2借款、股东资金、利息、还本和资金耗尽诊断。

这些文件只是规划名称，项目发起人逐卡授权前不得提前创建实现。

## 物理隔离规则

- 不得把SYN-B1逻辑写入旧`src/sg2*.py`、`src/sg3*.py`或`src/synthetic_ledger.py`；
- 不得直接导入上述旧生成器和旧账本模块；
- 不得读取旧生成数据作为运行时输入；
- 未来输出使用独立`data/synthetic_generated/syn_b1/`目录；
- 若确需复用通用能力，必须先由Sol冻结版本中立接口，再由Terra放入独立公共命名空间；不得复制两套业务算法。

每张任务卡验收都必须包含静态导入扫描、旧文件差异检查和相关回归测试。
