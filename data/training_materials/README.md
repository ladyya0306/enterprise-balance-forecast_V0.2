# 第三轮训练资料

这个目录中的 `v1` 文件由 `tools/v3_prepare_training_materials.py` 在 2026-09-23 从 780 户原始样本和已核对用途清单生成。原始样本没有被改动。

`v1` 下有三种资料，各按“学习”“区间校准”“开发测试”分为三个 CSV：

- `每天余额收入支出`：每天的余额、收入、支出和交易笔数。
- `每天余额收入支出及用途`：在前一类资料上增加每种用途当天的收入金额、支出金额和笔数。
- `逐笔金额余额用途`：每一笔金额、该笔后的余额、用途中文名称和固定代码。

用途中文名称与固定代码对照表也在 `v1`。代码只是类别名称，不能作为金额或大小顺序使用。原备注类型保存在逐笔表的 `source_note_type` 中，只供回查；主比较程序不读取它。
